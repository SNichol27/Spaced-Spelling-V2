# Supabase Database Schema & Setup

## Phase 1: Database Setup Instructions

### Step 1: Create Supabase Project

1. Go to https://supabase.com
2. Create a new project
3. Note your project URL and anon key from Project Settings → API

### Step 2: Run Database Schema

In Supabase, go to **SQL Editor** and run the following SQL:

```sql
-- Enable UUID extension
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- ============================================================
-- PROFILES TABLE (extends Supabase auth.users)
-- ============================================================
CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  email TEXT UNIQUE NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- ============================================================
-- CLASSES TABLE
-- ============================================================
CREATE TABLE classes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  teacher_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  schedule TEXT NOT NULL CHECK (schedule IN ('expanding_spacing', 'fixed_spacing', 'control')),
  weeks_in_year INTEGER NOT NULL CHECK (weeks_in_year > 0 AND weeks_in_year <= 52),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  CONSTRAINT unique_class_per_teacher UNIQUE(name, teacher_id)
);

CREATE INDEX idx_classes_teacher_id ON classes(teacher_id);

-- ============================================================
-- SPELLING LISTS TABLE
-- ============================================================
CREATE TABLE spelling_lists (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  class_id UUID NOT NULL REFERENCES classes(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  week_taught INTEGER NOT NULL,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  CONSTRAINT valid_week CHECK (week_taught > 0)
);

CREATE INDEX idx_spelling_lists_class_id ON spelling_lists(class_id);
CREATE INDEX idx_spelling_lists_week ON spelling_lists(week_taught);

-- ============================================================
-- SPELLING WORDS TABLE
-- ============================================================
CREATE TABLE spelling_words (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  list_id UUID NOT NULL REFERENCES spelling_lists(id) ON DELETE CASCADE,
  word TEXT NOT NULL,
  word_order INTEGER NOT NULL,
  definition TEXT, -- Optional, generated by AI or dictionary fallback
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  CONSTRAINT valid_order CHECK (word_order > 0 AND word_order <= 10)
);

CREATE INDEX idx_spelling_words_list_id ON spelling_words(list_id);

-- ============================================================
-- SCHEDULED REVIEWS TABLE
-- ============================================================
CREATE TABLE scheduled_reviews (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  list_id UUID NOT NULL REFERENCES spelling_lists(id) ON DELETE CASCADE,
  class_id UUID NOT NULL REFERENCES classes(id) ON DELETE CASCADE,
  review_number INTEGER NOT NULL CHECK (review_number > 0),
  scheduled_week INTEGER NOT NULL CHECK (scheduled_week > 0),
  status TEXT DEFAULT 'pending' CHECK (status IN ('pending', 'completed')),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  CONSTRAINT unique_review_per_list UNIQUE(list_id, review_number)
);

CREATE INDEX idx_scheduled_reviews_list_id ON scheduled_reviews(list_id);
CREATE INDEX idx_scheduled_reviews_class_id ON scheduled_reviews(class_id);
CREATE INDEX idx_scheduled_reviews_week ON scheduled_reviews(scheduled_week);
CREATE INDEX idx_scheduled_reviews_status ON scheduled_reviews(status);

-- ============================================================
-- ROW LEVEL SECURITY (RLS) POLICIES
-- ============================================================

-- Enable RLS on all tables
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE classes ENABLE ROW LEVEL SECURITY;
ALTER TABLE spelling_lists ENABLE ROW LEVEL SECURITY;
ALTER TABLE spelling_words ENABLE ROW LEVEL SECURITY;
ALTER TABLE scheduled_reviews ENABLE ROW LEVEL SECURITY;

-- ============================================================
-- PROFILES POLICIES
-- ============================================================

-- Users can only view their own profile
CREATE POLICY "Users can view own profile"
  ON profiles FOR SELECT
  USING (auth.uid() = id);

-- Users can update their own profile
CREATE POLICY "Users can update own profile"
  ON profiles FOR UPDATE
  USING (auth.uid() = id)
  WITH CHECK (auth.uid() = id);

-- ============================================================
-- CLASSES POLICIES
-- ============================================================

-- Teachers can view only their own classes
CREATE POLICY "Teachers can view own classes"
  ON classes FOR SELECT
  USING (auth.uid() = teacher_id);

-- Teachers can create classes
CREATE POLICY "Teachers can create classes"
  ON classes FOR INSERT
  WITH CHECK (auth.uid() = teacher_id);

-- Teachers can update their own classes
CREATE POLICY "Teachers can update own classes"
  ON classes FOR UPDATE
  USING (auth.uid() = teacher_id)
  WITH CHECK (auth.uid() = teacher_id);

-- Teachers can delete their own classes
CREATE POLICY "Teachers can delete own classes"
  ON classes FOR DELETE
  USING (auth.uid() = teacher_id);

-- ============================================================
-- SPELLING LISTS POLICIES
-- ============================================================

-- Teachers can view spelling lists for their classes only
CREATE POLICY "Teachers can view spelling lists for their classes"
  ON spelling_lists FOR SELECT
  USING (
    class_id IN (
      SELECT id FROM classes WHERE teacher_id = auth.uid()
    )
  );

-- Teachers can create spelling lists for their classes
CREATE POLICY "Teachers can create spelling lists for their classes"
  ON spelling_lists FOR INSERT
  WITH CHECK (
    class_id IN (
      SELECT id FROM classes WHERE teacher_id = auth.uid()
    )
  );

-- Teachers can update spelling lists for their classes
CREATE POLICY "Teachers can update spelling lists for their classes"
  ON spelling_lists FOR UPDATE
  USING (
    class_id IN (
      SELECT id FROM classes WHERE teacher_id = auth.uid()
    )
  )
  WITH CHECK (
    class_id IN (
      SELECT id FROM classes WHERE teacher_id = auth.uid()
    )
  );

-- Teachers can delete spelling lists for their classes
CREATE POLICY "Teachers can delete spelling lists for their classes"
  ON spelling_lists FOR DELETE
  USING (
    class_id IN (
      SELECT id FROM classes WHERE teacher_id = auth.uid()
    )
  );

-- ============================================================
-- SPELLING WORDS POLICIES
-- ============================================================

-- Teachers can view spelling words for their lists
CREATE POLICY "Teachers can view spelling words for their lists"
  ON spelling_words FOR SELECT
  USING (
    list_id IN (
      SELECT id FROM spelling_lists
      WHERE class_id IN (
        SELECT id FROM classes WHERE teacher_id = auth.uid()
      )
    )
  );

-- Teachers can create spelling words for their lists
CREATE POLICY "Teachers can create spelling words for their lists"
  ON spelling_words FOR INSERT
  WITH CHECK (
    list_id IN (
      SELECT id FROM spelling_lists
      WHERE class_id IN (
        SELECT id FROM classes WHERE teacher_id = auth.uid()
      )
    )
  );

-- Teachers can update spelling words for their lists
CREATE POLICY "Teachers can update spelling words for their lists"
  ON spelling_words FOR UPDATE
  USING (
    list_id IN (
      SELECT id FROM spelling_lists
      WHERE class_id IN (
        SELECT id FROM classes WHERE teacher_id = auth.uid()
      )
    )
  )
  WITH CHECK (
    list_id IN (
      SELECT id FROM spelling_lists
      WHERE class_id IN (
        SELECT id FROM classes WHERE teacher_id = auth.uid()
      )
    )
  );

-- Teachers can delete spelling words for their lists
CREATE POLICY "Teachers can delete spelling words for their lists"
  ON spelling_words FOR DELETE
  USING (
    list_id IN (
      SELECT id FROM spelling_lists
      WHERE class_id IN (
        SELECT id FROM classes WHERE teacher_id = auth.uid()
      )
    )
  );

-- ============================================================
-- SCHEDULED REVIEWS POLICIES
-- ============================================================

-- Teachers can view reviews for their classes
CREATE POLICY "Teachers can view reviews for their classes"
  ON scheduled_reviews FOR SELECT
  USING (
    class_id IN (
      SELECT id FROM classes WHERE teacher_id = auth.uid()
    )
  );

-- Teachers can create reviews for their classes
CREATE POLICY "Teachers can create reviews for their classes"
  ON scheduled_reviews FOR INSERT
  WITH CHECK (

    )
  );

-- Teachers can update reviews for their classes
CREATE POLICY "Teachers can update reviews for their classes"
  ON scheduled_reviews FOR UPDATE
  USING (
    class_id IN (
      SELECT id FROM classes WHERE teacher_id = auth.uid()
    )
  )
  WITH CHECK (
    class_id IN (
      SELECT id FROM classes WHERE teacher_id = auth.uid()
    )
  );

-- Teachers can delete reviews for their classes
CREATE POLICY "Teachers can delete reviews for their classes"
  ON scheduled_reviews FOR DELETE
  USING (

```

### Step 3: Configure Supabase Auth

1. Go to **Authentication → Providers → Email**
2. Enable Email Auth (default is on)
3. Go to **Authentication → URL Configuration**
4. Add redirect URLs:
   - Development: `http://localhost:3000/auth/callback`
   - Production: `https://your-app.vercel.app/auth/callback`

### Step 4: Get Your Credentials

1. Go to **Project Settings → API**
2. Copy:
   - Project URL → `NEXT_PUBLIC_SUPABASE_URL`
   - Anon Key → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. Go to **Project Settings → API → Service Role Key** (only visible to project owner)
4. Copy → `SUPABASE_SERVICE_ROLE_KEY`

### Step 5: Create `.env.local` file

Copy `.env.example` to `.env.local` and fill in your Supabase credentials and OpenAI API key.

## Database Design Notes

### Why This Structure?

1. **profiles** extends Supabase auth.users with teacher metadata
2. **classes** ensures one teacher owns one class (no sharing)
3. **spelling_lists** must belong to exactly one class (prevents cross-class data leak)
4. **spelling_words** are immutable once created; editing list updates words but preserves review links
5. **scheduled_reviews** reference both class AND list explicitly (double-check against accidents)
6. **RLS Policies** enforce data access at database level (not frontend)

### Key Constraints

- `weeks_in_year` must be 1-52 (validated at database level)
- `week_taught` must be valid (validated by application, not database)
- Reviews are only created if `scheduled_week <= weeks_in_year`
- Deleting a list cascades to delete its words AND reviews (no orphans)
- Teachers can ONLY access their own data (enforced by RLS policies)

### Indexes

Indexes are created on frequently queried columns:
- `teacher_id` (list all classes for a teacher)
- `class_id` (list lists/reviews for a class)
- `week_taught` and `scheduled_week` (find reviews by week)
- `status` (find pending reviews)
